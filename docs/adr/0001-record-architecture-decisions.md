# ADR 0001 — Architekturentscheidungen dokumentieren

- **Status:** akzeptiert
- **Datum:** 2026-08-30

## Kontext

Das Projekt wird über acht Phasen hinweg gebaut. Entscheidungen aus frühen
Phasen wirken in späten Phasen weiter, und die Begründung geht sonst verloren.

## Entscheidung

Jede Architekturentscheidung mit Tragweite wird als kurzes ADR in `docs/adr/`
festgehalten: fortlaufend nummeriert, mit Status, Kontext, Entscheidung und
Konsequenzen. Kurz halten — eine Seite reicht.

## Konsequenzen

Ein zusätzlicher Schritt bei größeren Entscheidungen. Dafür ist später
nachvollziehbar, warum etwas so ist, wie es ist.
